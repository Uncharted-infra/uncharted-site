# uncharted-site

Consumer marketplace + landing for Uncharted — local sweet shops, starting in Alpharetta, GA.
Lives at **uncharted.sh**. No secrets here — auth runs on `map.uncharted.sh`.

```bash
pnpm install
cp .env.example .env.local
pnpm dev                  # http://localhost:3000
```

See `AGENTS.md` and `../docs/product.md`.
